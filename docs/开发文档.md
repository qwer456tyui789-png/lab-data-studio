## 1. 项目概述

### 1.1 一句话定位

**一个纯前端、数据不出本机的“实验数据工作台”**：把实验/作业中的表格录入、公式计算、图表生成、趋势线拟合、多图联动和结果导出，收进一个打开即用的网页。

### 1.2 要解决的问题

| 痛点 | 常见做法 | 本项目对应设计 |
|---|---|---|
| 实验数据散落在 Excel、纸质记录和聊天文件里 | 多份表格反复复制 | 数据集 + 行/列编辑 + CSV 导入，统一存到浏览器 IndexedDB |
| 通用表格工具学习成本高，公式和图表割裂 | 先算完再插图，改数据后图不同步 | 公式列是数据的一部分，改原始值后图表与看板自动重算 |
| 画图要选类型、选 X/Y、调样式，反复试错 | 凭经验逐个试 | 本地规则式推荐，按日期/分类/相关性/量纲给出 1–3 条可解释建议 |
| 多张图之间无法联动 | 截图拼报告 | 按“同名列”跨数据集联动，点击图表即筛选看板 |
| 数据上传云端有隐私顾虑 | 发到在线工具 | 无后端、无网络请求、无遥测，数据只在本机浏览器 |
| 实验报告需要可复现的图表与数据 | 手工整理 | CSV/PNG 导出，PNG 以 2 倍像素导出，适合直接插入报告 |

### 1.3 设计目标与非目标

**目标**

1. 完成“录入 → 公式/清洗 → 图表 → 联动看板 → 导出”的可运行闭环。
2. 零后端、零账号、零网络依赖，刷新/重开浏览器后数据仍在。
3. 公式、统计、推荐等核心逻辑可单元测试，不依赖 UI。
4. 运行步骤短、依赖少，评审可在 5 分钟内复现。

**当前版本的非目标**

- 不做多人实时协作、云同步、账号体系。
- 不做 Excel 全格式兼容（仅 CSV/TSV；`.xlsx` 需先另存为 CSV）。
- 不做完整的统计检验（t 检验、ANOVA、置信区间等），当前只提供线性回归、R²、Pearson 相关系数与描述性统计。
- 不做移动端专门适配；界面按桌面浏览器设计。
- 不做运行时大模型调用；“智能图表推荐”是本地确定性规则引擎，不是 LLM。

## 2. 需求分析

### 2.1 目标用户与典型场景

**主要用户**：需要记录实验数据、画图并写报告的大学生。

| 场景 | 数据特征 | 用到的能力 |
|---|---|---|
| 单摆测重力加速度 | 日期、组别、摆长、周期；需要由周期公式算 g，再做 L–T² 图 | 公式列、公式引用公式、散点图、线性趋势线、R² |
| 分光光度法标准曲线 | 浓度、吸光度、多个重复样本；需要标准曲线与未知样反算 | 数值列、散点图、趋势线、公式列 |
| 课程成绩分析 | 班级/学号、多次成绩、加权总分；分类多、有空值 | 文本分类、加权公式、柱状图/饼图、看板联动 |
| 环境监测 | 时间序列、多个站点、温度/湿度/CO₂ | 日期列、多 Y 折线、跨数据集联动、筛选 |

### 2.2 功能清单与实现状态

| 赛题要求 | 本项目实现 | 状态 |
|---|---|---|
| 结构化表格录入 | 行/列增删、列名与类型编辑、单元格编辑、Excel 区域粘贴自动扩行列 | 已实现 |
| 折线/柱状/散点图 | 折线、柱状、散点；额外提供面积图、饼图 | 已实现 |
| 图表样式自定义 | 标题/轴名、8 色调色板、单系列颜色、图例、数值标签、平滑、面积、数据点、堆叠、横向柱状 | 已实现 |
| CSV/PNG 导出 | CSV（UTF-8 BOM、RFC 4180 转义）、PNG（2x、白底、中文正常） | 已实现 |
| 本地持久化 | IndexedDB，320ms 防抖自动保存；localStorage 降级 | 已实现 |
| 数据清洗与校验（进阶） | 列类型推断、数值合法性校验、空值/错误码提示、CSV 规范化 | 部分实现 |
| 公式计算与趋势线（进阶） | 自研公式引擎、公式列依赖、线性回归趋势线与 R² | 已实现 |
| 多图联动 Dashboard（进阶） | 最多 4 图、按同名列跨数据集联动、点击筛选 | 已实现 |
| AI 辅助图表推荐（进阶） | 本地规则式推荐（日期/分类/相关性/量纲/多样性），可解释、无需 API | 以规则引擎实现 |

> **关于“AI 推荐”的边界**：赛题写的是“AI 辅助图表推荐”。本项目选择把它实现为**可解释的本地规则引擎**，原因是：实验数据涉及隐私，不应上传；规则结果可复现、可测试；不把“AI”当成包装词。开发过程中使用 AI 编程助手，属于“AI 工具运用”，与运行时推荐是两件事，均在 README 中分开声明。

### 2.3 非功能需求

| 维度 | 设计/现状 | 说明 |
|---|---|---|
| 隐私 | 无后端、无外部请求、无埋点 | 数据只写入当前浏览器的 IndexedDB；清除站点数据会丢失 |
| 可复现 | `npm install` → `npm test` → `npm run dev` | 依赖锁定在 `package-lock.json` |
| 兼容性 | 现代 Chromium / Edge / Firefox / Safari | 依赖 IndexedDB、Blob、URL.createObjectURL、ResizeObserver；不支持 IE |
| 性能 | 面向百至千行实验数据 | 表格未做虚拟滚动；万行级数据可能卡顿（见 §13 限制） |
| 可访问性 | 基础键盘操作与焦点样式 | 未做完整 WCAG 审计 |
| 部署 | 任意静态服务器；`base: './'` 支持子路径 | 不能用 `file://` 直接打开，原因见 §8 |

## 3. 技术选型

### 3.1 选型表

| 层 | 选择 | 版本 | 理由 | 代价 |
|---|---|---|---|---|
| 视图 | Vue 3（Composition API + `<script setup>`） | 3.5.x | 单文件组件、响应式简单、团队上手快 | 需要理解 `reactive`/`computed`/`watch` |
| 构建 | Vite | 6.x | 开发热更新快、静态构建简单、`base: './'` 易部署 | 无 SSR |
| 图表 | Apache ECharts | 5.6.x | 折线/柱/散点/饼图成熟，Canvas 导出 PNG 方便 | 包体较大，已单独分包 |
| 存储 | IndexedDB + `idb` | 8.x | 容量大、异步、结构化；`idb` 提供 Promise 封装 | 需处理版本迁移与失败降级 |
| 测试 | Vitest | 3.x | 与 Vite 同源、零配置跑纯函数测试 | 未覆盖 UI/E2E 自动化 |
| 状态 | 自研 `reactive` 单例 | — | 规模小，避免引入 Pinia 的额外概念与依赖 | 需要自己维护动作与不变量 |
| 路由 | 无 | — | 三个 Tab 用一个状态切换即可 | 无法深链到某个图表 |
| UI 库 | 无 | — | 避免样式冲突与包体膨胀；设计变量集中在 `base.css` | 组件需自己写 |

### 3.2 为什么坚持“纯前端”

- **隐私**：实验数据、成绩数据可能包含个人信息，上传云端会带来合规与信任成本。
- **可运行性**：评审只需 Node 环境，不需要数据库、密钥或后端服务。
- **可复现**：没有网络波动、API 限额、服务端版本差异。
- **代价**：没有跨设备同步、没有服务端备份、浏览器清数据会丢失；这些在 README 中明确提示。

### 3.3 关键依赖的许可证

运行时依赖：Vue（MIT）、ECharts（Apache-2.0）、idb（ISC）。开发依赖：Vite、`@vitejs/plugin-vue`、Vitest（均 MIT）。完整版本与来源见 README 的“第三方资源来源与许可证声明”。项目未使用外部 CDN、在线字体、图标库或第三方数据接口。

### 4.4 关键设计决策与取舍

| 决策 | 选择 | 原因 | 代价/风险 |
|---|---|---|---|
| 数据持久化 | IndexedDB，localStorage 兜底 | 容量大、异步；兜底保证隐私模式仍可用 | 清站点数据即丢失；无跨设备 |
| 公式实现 | 自研 tokenizer + Pratt parser，禁用 `eval` | 避免任意代码执行；可给出精确错误码；可测试 | 语法比 Excel 小；维护成本高 |
| 公式列存储 | 只存公式源串，不存计算结果 | 原始数据变化后结果自动一致；快照更小 | 每次加载/编辑需重算 |
| 推荐实现 | 本地规则引擎 | 隐私、可复现、可解释、无 API 成本 | 不如 LLM 灵活；规则需维护 |
| 看板联动 | 按“列名”跨数据集匹配 | 不同数据集列 ID 不同，按名称更符合用户直觉 | 同名列语义可能不同；需用户确认 |
| 看板容量 | 最多 4 图 | 一屏可读、避免过度拥挤 | 大屏用户可能不够 |
| 图表聚合 | 折线/柱/面积按 X 分组取均值，饼图求和 | 重复 X 值（如多次测量）不丢点，展示趋势 | 均值可能掩盖组内差异；后续可加“显示原始点” |
| PNG 导出 | 客户端 `getDataURL` | 无后端、无上传 | 依赖 Canvas；超大图内存占用高 |
| CSV 解析 | RFC 4180 子集 | 覆盖 Excel 常见导出 | 不保证所有边缘格式 |
| 测试策略 | 领域层单测 + 手工 E2E | 投入产出比高 | UI 回归依赖人工 |

## 5. 数据模型与持久化

### 5.1 内存模型（示意）

```js
{
  version: 1,
  datasets: [
    {
      id: 'ds_...',
      name: '单摆测重力加速度',
      columns: [
        { id: 'col_...', name: '摆长L(cm)', type: 'number', formula: null },
        { id: 'col_...', name: '周期T(s)', type: 'number', formula: '[t50(s)] / 50' },
        { id: 'col_...', name: 'g(m/s²)', type: 'number', formula: '4 * 3.1415926^2 * [摆长L(cm)] / 100 / [周期T(s)]^2' }
      ],
      rows: [
        { id: 'row_...', cells: { col_...: 40, col_...: 1.274, col_...: '' } }
      ]
    }
  ],
  charts: [
    {
      id: 'chart_...',
      datasetId: 'ds_...',
      name: 'L–T² 线性拟合',
      type: 'scatter',
      xColumnId: 'col_...',
      yColumnIds: ['col_...'],
      trendline: { enabled: true },
      style: { title: '...', palette: ['#...'], seriesColors: {}, showLegend: true }
    }
  ],
  dashboard: {
    chartIds: ['chart_...'],
    linkageName: '组别',
    filterValue: ''
  },
  ui: {
    activeTab: 'data',          // data | chart | dashboard
    activeDatasetId: 'ds_...',
    activeChartId: 'chart_...'
  }
}
```

> 说明：公式字符串只是示意；当前函数集见 §6.2，实际以代码为准。

### 5.2 实体与不变量

| 实体 | 关键字段 | 约束/说明 |
|---|---|---|
| Dataset | `id`、`name`、`columns`、`rows` | 名称用于展示；删除数据集会级联删除其图表 |
| Column | `id`、`name`、`type`、`formula` | `type` 为 `text`/`number`/`date`；公式列的 `formula` 非空，类型编辑受限 |
| Row | `id`、`cells` | `cells` 以列 ID 为键；原始值保持字符串/数字，计算值不落盘 |
| Chart | `id`、`datasetId`、`type`、`xColumnId`、`yColumnIds`、`trendline`、`style` | Y 至少一个数值列；类型为五种之一；删除列时需清理引用 |
| Dashboard | `chartIds`、`linkageName`、`filterValue` | 最多 4 图；`linkageName` 为跨数据集同名列名 |
| UI | `activeTab`、`activeDatasetId`、`activeChartId` | 仅用于恢复现场，不属于业务数据 |

**ID**：`uid(prefix)` 生成 `${prefix}_${Date.now().toString(36)}_${random6}`，例如 `col_lx3k2p_a1b2c3`。它不是加密随机数，只用于本地唯一标识；不要用于安全场景。

### 5.3 持久化机制

```text
用户编辑
  → store 响应式状态变化
  → watch(deep) 触发 scheduleSave()
  → 清除上一个定时器，320ms 后 saveState(snapshot)
  → IndexedDB.put('app-state', snapshot)
  → 成功：status = saved；失败：尝试 localStorage；再失败：status = error
```

| 项 | 实现 |
|---|---|
| 数据库 | IndexedDB `lab-data-studio`，版本 1 |
| 对象仓库 | `kv`，主键 `key` |
| 记录键 | `app-state` |
| 快照 | `{ version: 1, datasets, charts, dashboard, ui }` |
| 防抖 | 320ms；连续输入只写最后一次 |
| 降级 | `localStorage['lab-data-studio:state']` |
| 失败提示 | 顶栏显示“保存失败”，Toast 提示 |
| 清空 | 删除 IndexedDB 数据库 / 清除站点数据（当前无 UI 重置按钮） |
| 迁移 | 当前仅 `version === 1`；加载时对旧看板字段做规范化（`datasetId`/`linkageColumnId` → 按列名联动） |

**为什么用 320ms 防抖**：单元格输入是高频事件，逐字符写 IndexedDB 会造成明显卡顿；320ms 在“及时保存”和“输入流畅”之间取平衡。

**保存竞态**：每次调度使用递增序号；只有最新一次保存的结果会更新 UI 状态，避免旧写入把“已保存”覆盖成“保存中”。

**失败场景**：隐私模式、配额不足、浏览器禁用 IndexedDB。此时降级 localStorage；若两者都失败，界面仍可编辑，但刷新会丢数据，顶栏会明确提示。

## 6. 核心模块设计

### 6.1 状态层 `src/store/useStore.js`

**形态**：模块级 `reactive` 单例，组件直接 `import { store, ...actions }`。不引入 Pinia，原因是状态树小、动作集中，减少一层概念。

**主要动作**（按职责分组）：

| 分组 | 动作 | 说明 |
|---|---|---|
| 初始化 | `initStore()` | 读取快照；无数据/版本不符时写入种子数据；恢复选中项 |
| 数据集 | `createDataset` / `duplicateDataset` / `renameDataset` / `deleteDataset` / `selectDataset` | 创建时可传列/行（CSV 导入）；删除级联图表 |
| 列 | `addColumn` / `updateColumn` / `deleteColumn` | 列名唯一性、类型变更、公式列保护 |
| 行/单元格 | `addRow` / `deleteRow` / `setCell` / `pasteBlock` | 粘贴块自动扩行扩列、去尾部空行/空列 |
| 图表 | `createChart` / `updateChart` / `deleteChart` / `selectChart` | 默认样式合并；删除后修正选中项 |
| 看板 | `addToDashboard` / `removeFromDashboard` / `setDashboardLinkage` / `setDashboardFilter` | 最多 4 图；联动字段来自数据集同名列 |
| 保存 | `scheduleSave` / `saveNow` / `loadState` | 防抖、竞态序号、状态文案 |

**派生数据不落盘**：`computeDataset(dataset)` 在 `ChartView`/`DataTable` 中按需计算；快照只存原始单元格和公式源串。这样避免“公式结果与源数据不一致”的经典问题。

**粘贴扩表**：`pasteBlock` 解析制表符/换行分隔的二维文本，按当前选中单元格为锚点，必要时补行补列；末尾全空的行/列会被裁掉，避免 Excel 复制带出的空尾。

### 6.2 公式引擎 `src/lib/formula.js`

#### 6.2.1 语法

```ebnf
expr    := term (("+" | "-") term)*
term    := unary (("*" | "/") unary)*
unary   := ("+" | "-") unary | power
power   := primary ("^" unary)?          // 右结合
primary := number
         | "[" columnName "]"
         | func "(" [expr ("," expr)*] ")"
         | "(" expr ")"
```

- 数字：整数/小数；负数由一元 `-` 解析。指数用 `^` 表示，当前不支持 `1.2e-3` 这类科学计数法字面量。
- 列引用必须用方括号：`[摆长L(cm)]`，列名可含空格、中文、括号。
- 函数名大小写不敏感（实现中统一转小写匹配）。
- `^` 右结合：`2^3^2 = 2^(3^2) = 512`。
- 一元负号优先级低于 `^`：`-2^2 = -(2^2) = -4`。
- 乘除、加减左结合。

#### 6.2.2 解析与求值

| 阶段 | 实现 |
|---|---|
| 词法 | 逐字符扫描，产出 `number` / `ref` / `ident` / `op`（含 `+ - * / ^ ( ) ,`）/ `eof` |
| 语法 | Pratt parser；绑定力：`+ -` 10/11，`* /` 20/21，`^` 40/40，一元 `-` 30 |
| AST | `{ type: 'number'|'ref'|'call'|'unary'|'binary', ... }` |
| 校验 | `validateFormula(source, columns, selfName)` 检查语法、列是否存在、是否自引用 |
| 依赖 | `analyzeFormulas(columns)` 收集公式列引用，建图，DFS 三色标记循环 |
| 求值 | 按拓扑序逐列、逐行 `evaluateNode`；聚合函数取整列 |
| 输出 | 每行 `{ values, display, errors }`；公式错误显示 `#CODE` |

#### 6.2.3 函数集

| 函数 | 参数 | 语义 | 空值/错误行为 |
|---|---|---|---|
| `abs(x)` | 1 | 绝对值 | 非数值 → `VALUE` |
| `sqrt(x)` | 1 | 平方根 | 负数 → `VALUE` |
| `round(x, digits?)` | 1–2 | 四舍五入，`digits` 限制 0–10 | 非数值 → `VALUE` |
| `sum(...)` | ≥1 | 求和；列引用取整列数值 | 全空 → `0` |
| `avg(...)` | ≥1 | 平均；列引用取整列数值 | 无有效值 → `VALUE` |
| `min(...)` | ≥1 | 最小值；列引用取整列数值 | 无有效值 → `VALUE` |
| `max(...)` | ≥1 | 最大值；列引用取整列数值 | 无有效值 → `VALUE` |

聚合函数可接收多个参数（标量或列），列参数会展开为整列数值；错误单元格会被跳过，不污染整列聚合。

#### 6.2.4 依赖与循环

- 只有公式列之间的引用会进入依赖图；引用原始列不构成依赖。
- DFS 三色标记：遇到灰色节点时，把当前栈中环上的列标记为 `CYCLE`。
- 循环列不参与求值，整列显示 `#CYCLE`；依赖循环列的公式在引用到错误单元格时同样得到 `CYCLE`，不会无限递归。
- 缺失列 → `REF`；语法错误 → `SYNTAX`；除零 → `DIV0`；空值/非数字 → `VALUE`。
- **单格错误不拖垮整表**：每个单元格独立 try/catch，坏格子显示错误码，其余行继续计算。

#### 6.2.5 为什么不用 `eval` / `new Function`

- 任意代码执行风险；
- 无法给出稳定错误码；
- 难以做依赖分析与循环检测；
- 自研解析器可测试、可解释，代价是函数集较小。

#### 6.2.6 示例

```text
[周期T(s)] = [50次全振动时间t50(s)] / 50
[g(m/s²)]  = 4 * 3.1415926^2 * ([摆长L(cm)] / 100) / [周期T(s)]^2
[加权总分] = 0.3 * [平时] + 0.7 * [期末]
```

### 6.3 统计与趋势线 `src/lib/stats.js`

**线性回归**（最小二乘）：

```text
x̄ = Σx / n,  ȳ = Σy / n
Sxx = Σ(x - x̄)²
Sxy = Σ(x - x̄)(y - ȳ)
slope = Sxy / Sxx
intercept = ȳ - slope * x̄
SSres = Σ(y - (slope*x + intercept))²
Syy = Σ(y - ȳ)²
R² = 1 - SSres / Syy
```

| 条件 | 返回 |
|---|---|
| 有效点 `n < 2` | `null` |
| `Sxx = 0`（x 全相同） | `null` |
| `Syy = 0`（y 全相同） | `R² = 1` |
| 正常 | `{ intercept, slope, r2, n }`，`r2` clamp 到 `[0,1]` |

`formatEquation` 输出 `y = ax + b`，用于图表副标题。

**Pearson 相关**：成对剔除空值/非数值；`n < 3` 或任一方差为 0 返回 `null`；`r = Sxy / sqrt(Sxx * Syy)`。推荐模块用 `|r|` 选择散点图的两个数值列。

**列特征**：`distinctValues`、`numericValues`、`isMonotonic`（长度 < 3 返回 false），供推荐规则判断时间列、分类列、常量列。

### 6.4 CSV 解析与序列化 `src/lib/csv.js`

**解析**：RFC 4180 子集状态机。

| 特性 | 支持 |
|---|---|
| 字段分隔 | 逗号（CSV）/制表符（TSV） |
| 引号字段 | `"..."` 内的逗号、换行 |
| 双引号转义 | `""` → `"` |
| 换行 | CRLF / LF / CR |
| BOM | 自动剥离 UTF-8 BOM |
| 尾部空行 | 解析后由调用方过滤 |
| 列宽不齐 | `normalizeMatrix` 补空串到最大宽度 |

**序列化**：`serializeCSV(matrix, { bom: true })`。

- 行尾 CRLF，Excel 兼容；
- 含逗号、引号、换行的字段自动加引号并转义；
- 默认加 UTF-8 BOM，避免 Excel 打开中文乱码；
- 导出文件名由 `sanitizeFilename` 清洗，最长 80 字符。

**类型推断**：`inferColumnType(values)`。

- 全部非空值可转有限数字 → `number`；
- 全部匹配 `YYYY-MM-DD` → `date`；
- 否则 → `text`。

### 6.5 图表配置 `src/lib/chartOptions.js`

**输入**：`{ dataset, computedRows, chart, filterValue, linkageColumnId, forExport }`。  
**输出**：`{ option, trendlines }`，`option` 直接交给 ECharts。

| 处理 | 规则 |
|---|---|
| X 轴 | 数值列 → 数值轴，按数值升序分组；文本/日期 → 类目轴，按出现顺序 |
| 折线/面积/柱状 | 按 X 标签分组，Y 取组内均值；多 Y 列生成多系列 |
| 饼图 | 按分类分组，Y 求和；无坐标轴/grid |
| 散点 | 保留原始点 `[x, y]` 与 `rowId`；不聚合 |
| 横向柱 | 交换 X/Y 轴 |
| 堆叠 | 柱状/面积按系列堆叠 |
| 趋势线 | 仅折线/面积/散点；最小二乘；虚线；副标题显示方程与 R² |
| 联动过滤 | 若提供 `linkageColumnId` 与 `filterValue`，先过滤行再聚合 |
| 样式 | 标题、轴名、调色板、单系列颜色、图例、标签、平滑、数据点、面积 |
| 导出模式 | `forExport` 关闭动画，保证 PNG 稳定 |

**为什么折线/柱状取均值**：同一 X 可能有多行（重复测量、多个样本），直接覆盖会丢点；均值能表达趋势。散点保留原始点，避免均值掩盖分布。

**趋势线计算**：折线/面积/柱状用“分组均值点”回归；散点用原始点回归。趋势线数据单独返回，渲染为虚线系列；副标题显示 `y = ax + b` 与 `R²`。

### 6.6 规则式图表推荐 `src/lib/recommend.js`

推荐流程：

```text
列特征提取
  → 时间列候选 → 折线（必要时 + 面积）
  → 分类列候选 → 柱状 / 饼图
  → 数值列两两相关 → 散点（附趋势线）
  → 候选打分、去重、按类型多样性挑选
  → 最多 3 条建议（类型、标题、理由、X/Y、置信度）
```

| 规则 | 触发条件 | 置信度 |
|---|---|---|
| 时间折线 | `date` 列 distinct ≥ 2；或列名含“时间/日期/年/月/日”且数值单调 ≥ 3 个点 | `0.9 + min(0.05, points*0.005)` |
| 时间面积 | 在折线基础上，仅 1 个指标且非负 | 折线 -0.05 |
| 分类柱状 | `text` 列，非编号/备注，平均长度 ≤ 10，distinct 2–12，非近唯一 | `max(0.74, 0.9 - max(0, distinct-2)*0.012)` |
| 分类饼图 | 分类 distinct 2–5，指标非负，名称可累加（人数/数量/次数等） | 0.76（可累加）/ 0.66 |
| 数值散点 | 两个数值列，`|r|` 最大，n ≥ 3 | `min(0.95, 0.62 + |r|*0.33 + (n≥5?0.02:0))` |

**指标选择**：最多 2 个 Y 列；优先选择量纲接近的一对（`|log10(max|mean|,|std|,1e-9 的比值)| ≤ log10(20)`），否则只保留第一个，避免“温度 + 人数”共轴造成误读。

**多样性**：候选按 `type` 去重；先每类取最高分，再按分数补足，最多 3 条。推荐面板会显示中文理由，用户可一键应用，再在样式面板微调。

**边界**：规则不是“真 AI”；它不能理解字段语义（例如“成绩”和“体重”都可能是数值），因此理由与置信度只作为辅助，最终由用户决定。

### 6.7 联动看板 `src/components/DashboardView.vue`

- **联动字段**：`getDashboardLinkageNames()` 汇总所有数据集列名，优先选择在多个数据集中出现的同名列；下拉显示“该列出现在几个数据集”。
- **加入看板**：从当前数据集的图表中选择，最多 4 张；可移出。
- **过滤**：`filter-bar` 展示联动字段的去重值 chips；点击 chip 设置 `filterValue`；“全部/重置”清空。
- **图表点击**：ECharts `click` 事件把点击项的分类值写入 `filterValue`，实现“点柱状图 → 其他图联动”。
- **跨数据集**：`buildChartOption` 接收 `linkageColumnId`，按列名在当前数据集找同名列并过滤；列不存在时不过滤。
- **空态**：没有联动字段时提示“先让多个数据集拥有同名列”；看板为空时提示添加图表。

## 7. 关键流程

### 7.1 启动与恢复

```text
main.js → App.vue onMounted → initStore()
  → loadState()
      → IndexedDB 读取 app-state
      → 无数据/版本不符 → 写入 seed（胡克定律、自由落体 + 3 张图）
      → 规范化 dashboard/ui 选中项
  → 渲染三个 Tab
```

### 7.2 编辑与自动保存

```text
单元格 input → setCell() → store 状态变化
  → 公式列/图表 computed 重新计算
  → watch(deep) → scheduleSave()（320ms 防抖）
  → saveState() → IndexedDB
  → 顶栏状态：保存中 → 已保存 / 保存失败
```

### 7.3 新增公式列

```text
“ƒ 公式列” → FormulaDialog
  → 输入列名 + 表达式
  → 前 3 行预览（临时列 __preview__，computeDataset）
  → validateFormula() 检查语法/列存在/自引用
  → addColumn({ formula })
  → 表格显示 ƒ 标记；错误格显示 #CODE，hover 看错误文案
```

### 7.4 生成图表与导出 PNG

```text
ChartView → createChart(datasetId) 或推荐 apply
  → buildChartOption({ dataset, computedRows, chart })
  → EChart setOption
  → 样式面板修改 → updateChart → 重新 build
  → 导出：setOption({animation:false}) → 等 180ms
          → getDataURL({ type:'png', pixelRatio:2, backgroundColor:'#ffffff' })

```

### 7.5 CSV 导入 / 导出

```text
导入：file input → file.text() → parseCSV
  → 空文件/空表头校验 → normalizeMatrix
  → 表头去重（重复名加 _2/_3）→ inferColumnType
  → createDataset(name, { columns, rows })

导出：DataTable 工具栏 → 当前数据集矩阵
  → serializeCSV(matrix, { bom:true }) → downloadText(.csv)
```

### 7.6 看板联动

```text
DashboardView 选择联动字段（同名列）
  → 加入最多 4 张图
  → 点击 chip / 图表元素 → setDashboardFilter(value)
  → 每张图 buildChartOption 按同名列过滤
  → “全部/重置”清空 filterValue
```

## 10. 工程规范、安全与隐私

### 10.1 Git 与协作

- 主分支 `main`；当前由核心开发直接提交，后续建议功能分支 + PR。
- 提交信息建议采用 Conventional Commits：`feat:`、`fix:`、`test:`、`docs:`、`refactor:`。
- 提交前至少运行 `npm test` 与 `npm run build`。
- 成员分工与提交记录见 [成员排名.md](./成员排名.md)。

### 10.2 代码风格

- 2 空格缩进、单引号、无分号（与现有文件一致）；
- Vue 组件使用 `<script setup>`；
- 领域函数保持纯函数，便于测试；
- 新增依赖前先评估许可证与包体。

### 10.3 安全

| 风险 | 处理 |
|---|---|
| 公式任意代码执行 | 自研 parser，禁用 `eval`/`new Function` |
| XSS | Vue 文本插值默认转义；未使用 `v-html` 渲染用户数据 |
| CSV 公式注入 | 当前导出仅做 RFC 4180 转义，未对 `= + - @` 开头单元格加前缀；导入来源需可信（见限制） |
| 数据泄露 | 无网络请求、无遥测；数据仅存当前 origin 的 IndexedDB |
| 本地数据被同源脚本读取 | 无第三方脚本；部署时避免在页面注入不可信脚本 |
| 文件导入 | 仅读取用户选择的 `.csv` 文本；不执行文件内容 |

### 10.4 隐私

- 不收集姓名、学号、设备信息；
- 不调用任何外部 API；
- 不上传实验数据；
- 演示视频/截图中如含真实成绩，应打码或使用测试数据。

## 13. 已知限制与后续路线

### 13.1 已知限制

1. **无撤销/重做**：误删数据集/列只能重新录入；删除前有确认，但没有历史栈。
2. **表格未虚拟化**：百至千行流畅，万行级可能卡顿。
3. **CSV 公式注入未处理**：导出单元格若以 `= + - @` 开头，Excel 可能当公式执行；当前面向可信来源数据。
4. **无跨设备同步**：数据在单浏览器；换设备需 CSV 迁移。
5. **无完整统计检验**：只有线性回归/R²/Pearson，没有 t 检验、ANOVA、误差棒。
6. **无多工作表/多文件项目**：一个工作区内的数据集平铺；大型项目需分组。
7. **推荐是规则引擎**：不能理解字段语义，复杂数据可能给出保守或重复建议。
8. **无 PWA/Service Worker**：数据本地，但应用资源仍需 HTTP 访问。
9. **无 UI 自动化与 CI**：回归依赖手工脚本。
10. **无国际化**：界面为中文。

### 13.2 后续路线（按优先级）

| 优先级 | 功能 | 价值 |
|---|---|---|
| P1 | 撤销/重做（命令栈或快照） | 降低误操作成本 |
| P1 | 数据清洗面板：重复行、缺失值、IQR 异常值、类型错误汇总 | 补足赛题“清洗与校验” |
| P1 | 误差棒/重复测量统计（均值±SD） | 更贴近真实实验报告 |
| P2 | 报告导出（图表+参数+结论模板） | 从“画图”走到“报告” |
| P2 | 表格虚拟滚动 | 支撑万行数据 |
| P2 | 图表预设/主题、批量应用 | 提高多图效率 |
| P3 | 可选 LLM 推荐（本地开关、明确上传确认） | 增强语义理解，但需隐私设计 |
| P3 | PWA 离线安装 | 完全离线使用 |

## 14. 附录

### 14.1 错误码

| 码 | 含义 | 常见原因 | 处理 |
|---|---|---|---|
| `SYNTAX` | 公式语法错误 | 括号不匹配、运算符缺失、函数名拼错 | 检查表达式；看预览 |
| `REF` | 引用了不存在的列 | 列被删除/改名、方括号拼写错误 | 重新选择列名 |
| `VALUE` | 数值无效或为空 | 数值列含文本、引用空单元格、sqrt 负数 | 补数据/改类型 |
| `DIV0` | 除数为 0 | 分母为 0 | 检查分母/数据 |
| `CYCLE` | 循环引用 | A 引用 B，B 又引用 A | 拆环或改为原始列 |

### 14.2 公式示例

```text
# 周期
[周期T(s)] = [50次全振动时间t50(s)] / 50

# 重力加速度（L 由 cm 转 m）
[g(m/s²)] = 4 * 3.1415926^2 * ([摆长L(cm)] / 100) / [周期T(s)]^2

# 加权总分
[加权总分] = 0.3 * [平时] + 0.7 * [期末]

# 列聚合
[平均摆长] = avg([摆长L(cm)])
```
