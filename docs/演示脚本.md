# 演示脚本（3–5 分钟）

> 目标：在 4 分钟左右完整展示「录入 → 计算 → 出图 → 联动 → 导出 → 持久化」闭环，并说明技术亮点与 AI 使用方式。
> 建议：提前执行 `npm install && npm run dev`，浏览器窗口缩放到 100%–110%，关闭无关标签页。

## 演示前检查清单

- [ ] `npm run dev` 已启动，`http://localhost:5173` 打开正常
- [ ] 页面显示"已保存"，侧栏有两个示例数据集
- [ ] 录屏工具（分辨率 1080p、显示光标、麦克风正常）
- [ ] 关闭系统通知；把终端窗口最小化
- [ ] 如担心现场环境波动，可提前把 `output/playwright/` 下的截图作为备份

## 分镜脚本

### 0:00–0:20 开场：问题与定位

**画面**：应用首页（数据表格 Tab，胡克定律数据集）。

**讲解**：
> "这是实验数据工坊。实验数据经常散落在 Excel 和纸上，整理和画图很费时间。这个工具把数据记录、公式计算、图表生成和联动看板做成了一条本地化的工作流，所有数据都留在浏览器里，不上传服务器。"

**操作**：鼠标扫过顶栏「纯前端 · 数据留在本机」和「已保存」标识。

---

### 0:20–1:10 数据录入与校验

**画面**：仍停在「自由落体测重力加速度」数据表格（先点侧栏切换）。

**讲解**：
> "录入方式和表格软件一致，直接点单元格输入。数值列会校验格式，日期列要求标准格式；从 Excel 复制的区域也可以整块粘贴，行列不够会自动扩展。"

**操作**：
1. 在任意数值单元格输入一个非数字（如 `abc`），展示红框/提示后撤销；
2. 点击底部「＋ 添加一行」再删除，展示行操作；
3. （可选）在空白单元格演示一次 2×2 的 `Ctrl+V` 粘贴（提前复制好内容）。

---

### 1:10–1:50 公式列与趋势线

**画面**：指向 `重力加速度g(m/s²)` 公式列。

**讲解**：
> "派生量可以用公式列算出来，比如 `g = 2h/t²`。解析器是手写的，不用 eval，支持中文列名、括号和常用函数，循环引用和非法引用都会单独报错。右边是它引用的原始数据。"

**操作**：
1. 悬停公式单元格，展示完整公式提示；
2. 点「ƒ 公式列」，输入示例 `round([下落高度(m)]/[下落时间(s)], 2)`，展示前 3 行实时预览，点「取消」不保存；
3. 切到「图表」Tab，选中散点图，指向底部「趋势线：y = 0.0248x - 0.1，R² = 0.9984」。

> "趋势线用最小二乘回归，方程和 R² 直接标在图上，开题报告里可以直接引用。"

---

### 1:50–2:50 图表样式与导出

**画面**：「图表」Tab。

**讲解**：
> "支持折线、面积、柱状、散点和饼图，右边可以改标题、坐标轴、配色、图例、平滑、面积、横向柱状等；导出的 PNG 是两倍分辨率白底，中文不会缺字。"

**操作**：
1. 在右侧切换一次图表类型（如散点 → 折线 → 面积 → 饼图 → 散点），展示即时生效；
2. 点一个调色板色块或改标题，展示样式变化；
3. 点「导出 PNG」，打开下载完成提示（或展示已导出的图片）；
4. 回到数据表格点「导出 CSV」，说明带 BOM、Excel 打开中文正常。

---

### 2:50–3:40 智能推荐 + 联动看板

**画面**：「图表」Tab → 点「智能推荐」。

**讲解**：
> "推荐是本地规则引擎：它会看日期列、分类基数、数值之间的相关系数和量纲，给不同数据集不同的建议，每条都有置信度、引用真实统计量的理由和推荐列，可以一键生成图表。"

**操作**：
1. 打开推荐面板，朗读一条理由（例如引用了 r 值的散点图建议），点「应用」生成图表；
2. 切到「联动看板」，从上方下拉把「胡克定律」数据集的散点图加入看板，指向联动字段「组别（2 个数据集）」，说明联动按同名列跨数据集生效；
3. 点击任意柱子（如 B 组），展示两个数据集的图表同步过滤、记录数从 14 变成 6；
4. 再点一次或「重置筛选」恢复全量。

---

### 3:40–4:20 持久化与技术说明

**讲解**：
> "图表和看板配置都会自动保存到 IndexedDB。我现在刷新页面——数据、当前图表都还在。"

**操作**：按 F5 刷新，展示页面恢复、顶栏"已保存"。

**讲解**：
> "技术栈是 Vue 3 + Vite + ECharts，纯前端，没有后端；单元测试覆盖公式、回归、CSV、图表配置和推荐规则共 46 个用例，生产构建通过。图表推荐不调用任何外部 AI 接口。"

---

### 4:20–4:40 收尾

> "这就是实验数据工坊：录入、计算、出图、联动、导出、持久化都在一个页面完成，数据完全留在本机。谢谢观看。"

## 常见问题与兜底方案

| 场景 | 处理 |
|---|---|
| 页面空白或报错 | 确认 `npm run dev` 正常运行；重新打开 `http://localhost:5173` |
| 数据看起来不对 | 示例数据可能被改动，可在侧栏删除数据集后刷新，示例会自动重建 |
| PNG 没弹出下载 | 检查浏览器下载权限；演示时可直接展示 `output/playwright/` 中已导出图片 |
| 演示时间不足 | 跳过「添加公式列」「CSV 导出」两段，保留趋势线、推荐、联动、刷新四段 |
| 时间充裕 | 补录一段 Excel 多行粘贴、日期列校验、图表多 Y 指标堆叠 |
